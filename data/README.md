# Region data packs

Open map data for each unlocked region: street layouts, building footprints, reference photos, plus the region's look sheet.

Every file ingested records its source, licence and retrieval date in the pack's `SOURCES.md`. ODbL (OpenStreetMap, Overture buildings) and CC BY-SA (Mapillary) carry attribution and share-alike duties.

Never use Google Maps content (tiles, Photorealistic 3D Tiles, Street View) in any form.

Contributor photos: EXIF location is easy to fake, so it is never proof of where a photo was taken. Blur faces and licence plates before a photo enters a pack.
