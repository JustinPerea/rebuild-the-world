# Standard render scene

The Blender scene and one-command render script from `docs/art-style-guide.md` ("Standard render scene"): overcast sky plus a clear-sun variant, mid-grey ground, 1.8 m human silhouette, 1 m ruler, colour chart, six fixed cameras, 1,024 × 1,024 output to the asset's `preview/` folder. Renderer version and settings are pinned here.
